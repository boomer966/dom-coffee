# Дом кофе — сайт кофейни

Статичный сайт без сборки. Меню хранится в `content/menu.json` и редактируется через админку `/admin` (Decap CMS).

## Как владелец меняет меню

1. Открыть `https://<адрес-сайта>/admin` и войти по email и паролю.
2. «Меню» → «Позиции меню».
3. Добавить позицию — кнопка «Добавить позицию». Удалить — крестик справа. Порядок меняется перетаскиванием.
4. Временно скрыть позицию (стоп-лист) — выключить «Показывать на сайте».
5. Нажать «Опубликовать» → «Опубликовать сейчас». Через 1–2 минуты изменения появятся на сайте.

Видео: вертикальное, 3–5 секунд, лучше до 10 МБ. На сайте играет без звука.

## Подключение (один раз)

1. Netlify → Add new site → Import an existing project → GitHub → этот репозиторий. Build command — пусто, Publish directory — пусто (корень).
2. Site configuration → Identity → Enable Identity.
3. Identity → Registration → Invite only.
4. Identity → Services → Git Gateway → Enable.
5. Identity → Invite users → email владельца. Ей придёт письмо, по ссылке она задаёт пароль.

## Проверка на компьютере

```
python -m http.server 8765
npx decap-server
```

Сайт: http://localhost:8765, админка: http://localhost:8765/admin (правки пишутся прямо в файлы).
