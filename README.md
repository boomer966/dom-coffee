# Дом кофе — сайт кофейни

Статичный сайт без сборки. Всё, что меняет управляющая, лежит в `content/` и редактируется через админку `/admin` (Decap CMS), в том числе с телефона:

| Пункт админки | Файл | Что на сайте |
|---|---|---|
| Разделы меню | `content/categories.json` | кнопки над меню |
| Позиции меню | `content/menu.json` | карточки напитков и блюд |
| Контакты | `content/contacts.json` | «Обратная связь» → контактные данные |
| Наш коллектив | `content/team.json` | «Обратная связь» → сотрудники |

## Как управляющая меняет сайт

1. Открыть `https://<адрес-сайта>/admin` (с компьютера или телефона) и войти по email и паролю.
2. Выбрать пункт: «Разделы меню», «Позиции меню», «Контакты» или «Наш коллектив».
3. Добавить — кнопка «Добавить…». Удалить — крестик справа. Порядок меняется перетаскиванием.
4. Временно скрыть раздел, позицию или сотрудника — выключить «Показывать на сайте».
5. Нажать «Опубликовать» → «Опубликовать сейчас». Через 1–2 минуты изменения появятся на сайте.

Позиция привязана к разделу по названию: если переименовать раздел, у его позиций нужно выбрать раздел заново.

Видео: вертикальное, 3–5 секунд, лучше до 10 МБ. На сайте играет без звука.

## Подключение (один раз)

1. Netlify → Add new site → Import an existing project → GitHub → этот репозиторий. Build command — пусто, Publish directory — пусто (корень).
2. Site configuration → Identity → Enable Identity.
3. Identity → Registration → Invite only.
4. Identity → Services → Git Gateway → Enable.
5. Identity → Invite users → email владельца. Ей придёт письмо, по ссылке она задаёт пароль.

## Проверка на компьютере

```
python -m http.server 8765
npx decap-server
```

Сайт: http://localhost:8765, админка: http://localhost:8765/admin (правки пишутся прямо в файлы).
